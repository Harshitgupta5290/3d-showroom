Step 3
Load the base model (DeepSeek-Coder 6.7B)

We use DeepSeek-Coder because it already understands JavaScript and math. LoRA adds a thin adapter layer — only 1-2% of weights change, so training is fast and cheap.

from unsloth import FastLanguageModel
import torch

model, tokenizer = FastLanguageModel.from_pretrained(
    model_name   = "unsloth/deepseek-coder-6.7b-instruct-bnb-4bit",
    max_seq_length = 512,
    dtype          = None,
    load_in_4bit   = True,
)
model = FastLanguageModel.get_peft_model(
    model,
    r              = 16,
    target_modules = ["q_proj","k_proj","v_proj","o_proj",
                      "gate_proj","up_proj","down_proj"],
    lora_alpha     = 16,
    lora_dropout   = 0,
    bias           = "none",
    use_gradient_checkpointing = "unsloth",
)
Step 4
Load dataset and train

~400 examples × 3 epochs takes about 8-12 minutes on Colab T4. Total cost: $0 on free tier.

from datasets import load_dataset
from trl import SFTTrainer
from transformers import TrainingArguments

dataset = load_dataset(
    "json",
    data_files = "lumina_shapes_chatml.jsonl",
    split      = "train"
)

def format_chatml(example):
    msgs = example["messages"]
    text = ""
    for m in msgs:
        if   m["role"] == "system":    text += f"<|system|>\n{m['content']}\n"
        elif m["role"] == "user":      text += f"<|user|>\n{m['content']}\n"
        elif m["role"] == "assistant": text += f"<|assistant|>\n{m['content']}<|end|>\n"
    return {"text": text}

dataset = dataset.map(format_chatml)

trainer = SFTTrainer(
    model    = model,
    tokenizer = tokenizer,
    train_dataset = dataset,
    dataset_text_field = "text",
    max_seq_length = 512,
    args = TrainingArguments(
        per_device_train_batch_size = 4,
        gradient_accumulation_steps = 4,
        num_train_epochs = 3,
        learning_rate    = 2e-4,
        fp16             = not torch.cuda.is_bf16_supported(),
        bf16             = torch.cuda.is_bf16_supported(),
        logging_steps    = 10,
        output_dir       = "lumina_model",
        save_strategy    = "epoch",
        warmup_ratio     = 0.05,
        lr_scheduler_type = "cosine",
    ),
)
trainer.train()
Step 5
Export to GGUF for Ollama

GGUF is the format that Ollama uses to run models locally. Q4_K_M gives ~4GB file size with minimal quality loss.

# Save LoRA weights
model.save_pretrained_merged("lumina_merged", tokenizer, save_method="merged_16bit")

# Export to GGUF (Q4_K_M quantization)
model.save_pretrained_gguf("lumina_gguf", tokenizer, quantization_method="q4_k_m")

# Download the .gguf file
from google.colab import files
files.download("lumina_gguf/lumina_model_q4_k_m.gguf")
Result: LUMINA runs your fine-tuned model locally. No API key, no internet needed, unlimited requests. Response time ~200ms on Apple M-series, ~800ms on CPU.

Step 2
Register your model

Create a Modelfile that tells Ollama how to run your GGUF and what system prompt to use.

# Create Modelfile (save as ~/Modelfile)
FROM ./lumina_model_q4_k_m.gguf

SYSTEM """You are LUMINA, a Three.js particle shape expert. \
Generate JavaScript function bodies that return {x, y, z} \
coordinates. Use only Math.* functions. Coordinates in range -22 to 22. \
Return ONLY the raw function body, no explanation."""

PARAMETER temperature 0.3
PARAMETER num_ctx 512

# Register and start
ollama create lumina -f ~/Modelfile
ollama run lumina "create a butterfly shape"
Step 3
Connect LUMINA to your local model

Replace the callGeminiShape() function in app.html with this Ollama call. No API key needed — just ollama serve running in the background.

// Replace callGeminiShape() with this in app.html:
async function callGeminiShape(description, _apiKey) {
    const res = await fetch("http://localhost:11434/api/generate", {
        method: "POST",
        headers: {"Content-Type": "application/json"},
        body: JSON.stringify({
            model:  "lumina",
            prompt: `Create particle shape code for: ${description}`,
            stream: false,
            options: { temperature: 0.3, num_predict: 300 }
        })
    });
    if (!res.ok) throw new Error("Ollama not running — start with: ollama serve");
    const d = await res.json();
    return d.response.trim()
        .replace(/^```[\w]*\n?/, "")
        .replace(/\n?```$/, "")
        .trim();
}
